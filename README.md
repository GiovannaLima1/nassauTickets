# nassauTickets

## Descrição e Objetivo
Sistema de Controle de Atendimento para um Laboratório de Análises Clínicas, desenvolvido para gerenciar a emissão de senhas, filas de atendimento (Prioritária, Geral e Exames), painel de chamadas e relatórios gerenciais.
